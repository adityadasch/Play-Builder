Play Command Tool

A lightweight C++ compilation and configuration manager.

Usage

play [command]

-- Usage 

- `play` — Compile and run the active configuration.
- `play <filename>` — Compile and run the specified source file.
- `play -set:<name>` — Set the active configuration to `<name>`. If the configuration does not exist, Play creates a new configuration using a default template.
- `play -drop:<name>` — Delete the configuration named `<name>`. If the configuration does not exist, nothing is changed.
- `play -list` — List all available configurations.
- `play -help` — Display this help message.

-- Compile a Source File

play main.cpp

Play checks the first line of the source file for a dependency declaration:

// dep:a.ext;b.ext;c.ext

The `dep:` declaration specifies additional files to link during compilation. Separate multiple filenames with semicolons (`;`).

For example:

// dep:common.cpp;utils.cpp

Play automatically detects these dependencies and includes the specified files in the compilation process.

-- Configuration Management

Set or create a configuration:

play -set:debug


If `debug` does not exist, Play creates it from the default configuration template and makes it the active configuration.

Delete a configuration:

play -drop:debug

If `debug` does not exist, the command leaves the existing configurations unchanged.

List available configurations:

play -list

### Examples

play
play main.cpp
play -set:debug
play -drop:debug
play -list
play -help
